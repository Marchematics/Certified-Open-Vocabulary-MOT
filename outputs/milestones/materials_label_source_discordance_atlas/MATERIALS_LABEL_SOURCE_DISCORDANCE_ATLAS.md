# Materials Label-Source Discordance Atlas

Completed public-data atlas from MP-Alex exact-structure matches. The full denominator contains `43139` strict matches and `5060` exact-stability disagreements, discordance rate `0.1173`.

This is a frontier benchmark-reliability result and a source-label uncertainty diagnostic. It is not a positive independent validation of PARC, not a prospective materials-discovery claim, and not evidence that external materials databases are interchangeable ground truth.

The selected-set rows are imported from the existing discordance artifact to show source-condition sensitivity; they are not a candidate-level PARC release overlay.

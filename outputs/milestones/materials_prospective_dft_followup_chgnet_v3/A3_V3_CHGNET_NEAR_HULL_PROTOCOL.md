# A3-v3 CHGNet Near-Hull Prospective DFT Follow-Up Protocol

A3-v3 generates a prospective candidate pool from WBM near-hull parent prototypes using only isovalent or chemically similar substitutions. Public-label exclusion is conservative over locally available indexes. CHGNet scores are frozen before any new DFT outcomes. A DFT manifest is produced only if a predeclared strict or operational endpoint has a sufficiently large PARC release.

# SpaceNet 7 Prospective Audit Closeout

Status: **no-go as a second flagship positive result under the predeclared gate**.

This prospective trial was frozen before promotion of any new SpaceNet result. It trains a learned-geometry source on AOIs disjoint from the certification AOIs, excludes all earlier SpaceNet audit candidates by `path_id`, and prepares blank human audit sheets for calibration, release and raw top-K review.

The public milestone intentionally excludes the large learned candidate universe and all raw SpaceNet data. The included proxy planning tables use official labels only to decide whether a human audit would be likely to satisfy the predeclared endpoint; they are not human-audited FTR evidence.

## Proxy Planning Outcome

Using the upper planned calibration size (`n=1500`), the strongest proxy row was `alpha=0.2, K=25`, with `8/20` non-empty seeds and mean release `9.550`. This is below the `18/20` flagship threshold. Strict `alpha=0.10` rows were all certified refusal.

## Interpretation

The trial should **not** replace the existing SpaceNet K=50 human-confirmed diagnostic release. It is a prospective operating-envelope check showing that a new candidate-disjoint human-audit trial did not meet the second-flagship positive gate under the predeclared endpoints.

The manuscript should therefore keep the learned-hybrid CTC result as the flagship positive case, keep SpaceNet K=50 as a diagnostic human-audit release, and report this prospective SpaceNet trial only as no-go/protocol evidence unless human labels and a later predeclared expansion change the gate result.

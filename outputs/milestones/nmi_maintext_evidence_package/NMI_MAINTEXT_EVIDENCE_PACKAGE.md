# NMI Maintext Evidence Package

Status: completed paper-facing package.

This package converts completed non-A3 artifacts into exact manuscript sentences, figure source rows, and source SHA256 mappings. It does not edit the manuscript and does not create new evidence.

## Headline Discipline

- Primary headline rows: 1
- Explicit not-positive rows: 1
- The only primary headline in this package is the CTC active-audit strict transition.
- Materials audit-budget rows remain boundary/secondary, and materials prospective discovery remains forbidden.

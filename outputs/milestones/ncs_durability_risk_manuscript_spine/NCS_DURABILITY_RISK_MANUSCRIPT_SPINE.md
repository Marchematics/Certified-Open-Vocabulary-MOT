# NCS Durability-risk Manuscript Spine

Status: draft spine built from completed non-DFT evidence. DFT v2 is explicitly
decoupled as a pending optional slot.

## One-sentence Nugget

The durability of a computational materials release card is not primarily a
candidate-level energy-margin property; it is a chemical-system property
controlled by the t0 margin-landscape and exploration activity of the reference
database region in which the candidate sits.

## Main Claim Chain

1. Scientific candidate queues need release cards because verification is
   scarce and reference databases evolve.
2. PARC supplies a one-sided release/refusal certificate for a frozen queue and
   a specified reference version.
3. PARC-A shows that the certificate can direct scarce verification: in CTC,
   active one-sided audit reaches certified release at tiny budgets where random
   audit remains ineffective.
4. Materials screening exposes the version problem. t0 release-card utility does
   not automatically become a t1 alpha certificate after the MP hull changes.
5. The key constructive materials finding is durability-risk prediction:
   future release-card decay is predicted by t0 chemical-system margin
   landscape/activity features, not by candidate margin or raw rank.
6. Versioned recertification and conservative DFT v2 gates keep the paper honest:
   if the reference changes or DFT execution is workflow-limited, the correct
   output is risk triage, recertification, or refusal rather than inherited
   publication.

## DFT v2 Decoupling Rule

DFT v2 enters the main text only if the workflow-validity and efficacy gates in
`DFT_V2_NUMERIC_GATE_ADDENDUM.md` pass. Otherwise it remains Supplementary
workflow-limited evidence. The manuscript should be written and reviewed around
the completed durability-risk and active-verification results without waiting
for DFT v2.

## Forbidden Interpretations

- Do not describe the t0 public-label system features as label-free deployment

- Do not claim prospective materials discovery.
- Do not use completed-only DFT v2 FTR as a headline if the conservative
  workflow-validity gate fails.

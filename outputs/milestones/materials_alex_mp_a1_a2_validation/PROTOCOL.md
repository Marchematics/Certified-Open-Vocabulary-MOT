# Protocol

Reconstruct ALIGNN-FF WBM PARC rows at `alpha=0.10`, `rho=0.10`, `K=300`, then match unique raw/PARC candidates to alex-mp v20 by exact reduced formula plus pymatgen StructureMatcher. Evaluate independent FTR only on exact matches. Use alex-mp as a later external public snapshot for A1 quasi-temporal replay and as an independent DFT source for A2.

# Kappa Planning Sensitivity

Planning-only sensitivity tables. They estimate how many genuine independent-review disagreements would produce Cohen's kappa near selected values under existing label distributions.

These files are **not audit evidence** and contain no per-row synthetic labels. Do not use them as annotation results, agreement results, or paper-facing human-review evidence.

The reference value 0.84 is included only as a planning calculation; labels must never be changed to force a desired kappa.

# Public Outputs

- `milestones/tpami_reliability_fortress_v2/`: final frozen experiment/result bundle.
- `benchmarks/parc_certification_benchmark_v1/`: compact community benchmark package with audit labels, result tables, schemas, and a tiny fixture.

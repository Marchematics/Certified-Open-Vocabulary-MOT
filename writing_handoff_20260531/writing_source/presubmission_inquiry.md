Subject: Presubmission inquiry: Knowing when not to publish scientific AI candidates

Dear Editors,

We are writing to ask whether the enclosed manuscript scope would be of interest to *Nature Machine Intelligence* before full submission.

Scientific AI pipelines increasingly propose more candidates than can be verified, yet every released candidate enters a downstream scientific process: a crystal candidate enters a follow-up queue, a cell link enters a lineage graph, a building correspondence enters a persistence map and an animal detection enters an ecological record. Current pipelines often publish ranked lists even when negative labels are unavailable. In these settings, the central deployment question is not only whether a model scores well, but which candidates should be released and when the system should refuse to publish any set at all.

We introduce PARC, a release-time governance layer for frozen scientific candidate universes under scarce one-sided verification. The conceptual point is to separate prediction from publication: trust only verified positives, retain all remaining candidates as a conservative null superset, construct block-level false-candidate evidence and then issue either a certified release set or a certified refusal. The conceptual advance is treating refusal to publish as a first-class, calibrated scientific output. Within a fixed, covered candidate regime, the guarantee controls the expected released-set false fraction rather than per-run exceedance, per-candidate truth or every possible unobserved object.

The manuscript emphasizes consequence-level analyses rather than benchmark scores alone. Using only public WBM/Matbench labels and frozen model predictions, PARC changes a retrospective materials follow-up queue: for ALIGNN-FF top-500, it issues a certified stop without using held-out DFT labels at release time, and a matched-volume analysis shows that the value is certified stopping rather than rank improvement at fixed output size; at top-5000, it refuses a list that would send 2,577.4 unstable candidates downstream. The clean empirical-baseline frontier compares 11 practical baseline families and shows the same interpretation: for ALIGNN-FF \(K=500\), raw top-\(K\) FTR is 0.327, whereas PARC and matched-size raw top-\(R\) both have FTR 0.048, avoiding 158.30 unstable follow-ups relative to the requested queue. In CTC \(K=100\), an active audit-budget frontier shows that targeted audit reaches strict seed-stable release with 0.5% of the calibration-candidate budget, yielding 2,000 released links and no observed false releases, while matched-budget random audit releases in 0/20 seeds. Using official ground truth, the same release/refusal decision prevents 2,907.5--3,997.1 false lineage edges per seed in CTC high-volume queues and 3,398.9 false same-building persistence links per seed in a SpaceNet randomized stress row. An internally audited iWildCam vignette exercises the same interface under real partial verification, with 167/167 released animal-present candidates confirmed, without substituting for external annotation.

PARC's final self-consistency threshold has the denominator-aware form of e-BH when valid e-values and no conflicts are already supplied. We view the contribution not as a new multiple-testing threshold, but as the construction of deployable false-candidate e-values from one-sided partial verification, a compatibility-aware release-or-refuse interface and evidence that this interface changes downstream scientific artifacts.

We explicitly delimit the scope. The materials consequence analyses are retrospective public-label computational follow-up analyses, not new materials discovery or experimental synthesis. The CTC and SpaceNet analyses use official labels to quantify downstream artifacts, not production deployments or benchmark-ranking claims. The frozen A3-v4 DFT follow-up arm is not reported as completed evidence: under the conservative QE-validity policy it fails the strict \(\alpha=0.10\) primary gate before any stability-FTR result is computed.

We believe the manuscript may be a good fit for *Nature Machine Intelligence* because it addresses a broad AI-for-science governance problem: how a scientific AI pipeline can abstain from over-publishing unsupported candidates when verification is one-sided and incomplete. We would be grateful for your view on whether this framing and scope are appropriate for full submission.

Sincerely,

The authors
